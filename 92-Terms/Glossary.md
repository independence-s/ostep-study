# OSTEP Terms

| Term | 中文建议 | 说明 |
|---|---|---|
| abstraction | 抽象 | 隐藏底层复杂性，给上层一个更简单的接口/模型 |
| virtualization | 虚拟化 | 将有限物理资源呈现为更易用的虚拟资源 |
| illusion | 假象 / 抽象效果 | OSTEP 常用于描述虚拟化制造出的“看起来像” |
| mechanism | 机制 | 系统“怎么做到” |
| policy | 策略 | 系统“多个选择中选哪个” |
| resource manager | 资源管理者 | OS 的核心角色之一 |
| standard library | 标准库 | 编程语言/运行环境提供的常用函数集合 |
| system call | 系统调用 | 用户程序请求内核服务的重要接口 |
| PID | 进程标识符 | 每个运行进程的标识 |
